# 銀行管理系統 - 系統操作與編譯指南

本文件說明如何建立執行環境、編譯 COBOL 程式碼以及操作銀行管理系統的各項選單功能。

> [!WARNING]
> 本專案僅作為程式碼寫法範例展示，並未實作任何資料加密或安全防護機制（如身分證字號、電話、餘額與交易明細等敏感資訊均為明文儲存）。請勿直接將本專案套用於實際的生產系統或商業環境中。

---

## 1. 環境建置與安裝 (WSL Debian)

如果您使用的是 Windows 系統，建議透過 **Windows Subsystem for Linux (WSL)** 搭配 Debian 或 Ubuntu 發行版來運行 GnuCOBOL 編譯器。

### 步驟 1: 啟用 Windows 的 WSL 功能
1. 以系統管理員身分開啟 PowerShell。
2. 執行以下指令啟用 Windows 子系統功能：
   ```powershell
   Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
   ```
3. 依系統提示重新啟動電腦。

### 步驟 2: 安裝與啟動 Linux 發行版 (以 Debian 為例)
1. 開啟 PowerShell，輸入以下指令安裝 Debian：
   ```powershell
   wsl --install -d Debian
   ```
2. 安裝完成後會自動開啟 Linux 終端機，依提示設定使用者名稱與密碼。

### 步驟 3: 安裝 GnuCOBOL 編譯器
1. 在 Linux 終端機中，更新系統套件清單：
   ```bash
   sudo apt-get update
   sudo apt-get upgrade
   ```
2. 安裝 GnuCOBOL 套件：
   ```bash
   sudo apt-get -y install gnucobol
   ```
3. 確認編譯器安裝成功：
   ```bash
   cobc --version
   ```

## 2. 程式編譯與執行

本專案的 COBOL 原始碼位於 [BANK.cbl](../BANK.cbl)。請遵循以下步驟進行編譯與執行：

### 步驟 1: 編譯 COBOL 程式
在 Linux 終端機進入專案目錄，執行以下編譯指令：
```bash
cobc -x -free BANK.cbl -o BANK
```
* `-x`：產出可執行的二進位檔 `BANK`。
* `-free`：告訴編譯器使用自由格式（Free Format）撰寫的代碼，不受傳統 COBOL 第 1-6 欄與 72-80 欄之格式限制。
* `-o BANK`：指定輸出檔名為 `BANK`。

### 步驟 2: 執行程式
```bash
./BANK
```

## 3. 系統選單操作說明

執行程式後，系統會顯示如下主選單介面：
```text
===============================
      銀行管理系統選單         
===============================
1. 新增客戶資料
2. 開立新帳戶
3. 存款
4. 提款
5. 轉帳
6. 查詢餘額
9. 離開系統
===============================
請輸入您的選擇 (1-9): 
```

### 功能 1：新增客戶資料
* **說明**：建立新客戶的個人資訊。
* **流程**：
  1. 輸入 `1` 並按下 Enter。
  2. 系統會顯示預計生成的客戶 ID（如 `客戶ID將為: 0000000005`）。
  3. 依序輸入以下資料：
     * **身分證字號**（例如 `A123456789`）
     * **客戶姓名**（例如 `王小明`）
     * **客戶地址**（例如 `台北市信義區信義路五段7號`）
     * **客戶電話**（例如 `0912345678`）
  4. 顯示 `客戶資料新增成功!`，並將資料寫入 [CUSTOMER.SAM](../CUSTOMER.SAM)。

### 功能 2：開立新帳戶
* **說明**：為已建立的客戶開立新的儲蓄或支票帳戶。
* **流程**：
  1. 輸入 `2` 並按下 Enter。
  2. 輸入要綁定的 **客戶 ID**。
  3. 系統驗證客戶 ID 是否存在於 [CUSTOMER.SAM](../CUSTOMER.SAM)：
     * 若不存在，顯示錯誤訊息並返回主選單。
     * 若存在，生成唯一帳號，並提示選擇帳戶類型：
       * 輸入 `S`：開立儲蓄帳戶 (Savings)
       * 輸入 `C`：開立支票帳戶 (Checking)
  4. 輸入 **初始存款金額**。
  5. 系統自動取得當前日期作為開戶日期，將狀態設為啟用（Active），寫入 [ACCOUNT.SAM](../ACCOUNT.SAM)，並在 [TRANS.SAM](../TRANS.SAM) 寫入一筆「初始存款」紀錄。

### 功能 3：存款作業
* **說明**：將資金存入指定帳戶。
* **流程**：
  1. 輸入 `3` 並按下 Enter。
  2. 輸入 **帳號**。
  3. 系統會驗證帳號是否存在、是否已關閉（Closed）或凍結（Suspended）。
  4. 輸入 **存款金額**（必須大於零）。
  5. 系統透過暫存機制更新該帳戶餘額，並在 [TRANS.SAM](../TRANS.SAM) 記錄一筆型態為 `D`（Deposit）、描述為「櫃台存款」的交易明細。

### 功能 4：提款作業
* **說明**：從指定帳戶中提取資金。
* **流程**：
  1. 輸入 `4` 並按下 Enter。
  2. 輸入 **帳號**。
  3. 系統驗證帳號狀態，並提示輸入 **提款金額**。
  4. 系統檢查餘額是否足夠：
     * 若餘額不足，顯示錯誤訊息並中止提款。
     * 若餘額充足，更新餘額，並在 [TRANS.SAM](../TRANS.SAM) 記錄一筆型態為 `W`（Withdrawal）、描述為「櫃台提款」的交易明細。

### 功能 5：轉帳作業
* **說明**：將資金從來源帳戶轉移至目標帳戶。
* **流程**：
  1. 輸入 `5` 並按下 Enter。
  2. 輸入 **來源帳號** 與 **目標帳號**（兩者不能相同，且帳戶狀態必須為啟用）。
  3. 輸入 **轉帳金額**。
  4. 系統檢查來源帳戶餘額是否足夠：
     * 若不足，顯示錯誤並退出。
     * 若充足，分別扣除來源帳戶餘額、增加目標帳戶餘額。
  5. 系統會在 [TRANS.SAM](../TRANS.SAM) 寫入兩筆交易紀錄：
     * 來源帳戶寫入一筆 `T`（Transfer）、描述為「轉出至帳號: [目標帳號]」的交易。
     * 目標帳戶寫入一筆 `T`（Transfer）、描述為「轉入自帳號: [來源帳號]」的交易。

### 功能 6：查詢餘額
* **說明**：顯示帳戶當前狀態、關聯客戶資訊以及最近 5 筆交易明細。
* **流程**：
  1. 輸入 `6` 並按下 Enter。
  2. 輸入 **帳號**。
  3. 系統顯示該帳戶的：
     * **帳戶資訊**：帳號、客戶 ID、類型、餘額、開戶日期、狀態。
     * **客戶資訊**：姓名、身分證字號、地址、電話。
     * **最近5筆交易記錄**：包含日期、時間、類型（存款/提款/轉帳）、金額、交易前後餘額與描述。

### 功能 9：離開系統
* **說明**：結束程式執行。
* **流程**：
  1. 輸入 `9` 並按下 Enter。
  2. 系統安全關閉所有開啟的資料檔案，顯示 `謝謝使用本系統，再見！` 並退出。
